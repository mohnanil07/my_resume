
# Resume React Website

This project is a modern, clean React-based website for displaying your resume. Built with Vite for fast development and optimized builds. Ready for deployment on GitHub Pages.

## Getting Started

1. **Install dependencies:**
   ```sh
   npm install
   ```
2. **Start the development server:**
   ```sh
   npm run dev
   ```
3. **Build for production:**
   ```sh
   npm run build
   ```

## Deploying to GitHub Pages

1. Set up the `homepage` field in `package.json` to your GitHub Pages URL (e.g., `https://yourusername.github.io/repo-name`).
2. Use a deployment tool like `gh-pages` or GitHub Actions to publish the `dist` folder.

## Customization

- Edit `src/App.jsx` to add your resume content and customize the design.
- Add more components as needed for sections like Experience, Education, Skills, etc.

---

This project was bootstrapped with [Vite](https://vitejs.dev/) and [React](https://react.dev/).
